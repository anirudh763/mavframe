# Synthetic packet scenarios

These tiny fixtures are generated locally; they are not captured flights or evidence of an attack.
Regenerate with `python3 tools/gen_scenarios.py` using the project's pymavlink test dependency
(v20 common dialect). Records contain an eight-byte big-endian capture timestamp followed by
one MAVLink v2 frame, system 1 / component 1, consecutive sequence numbers starting at zero.
Start time is 2023-11-14 22:13:20 UTC, with one-second record spacing.

| ID / file prefix `scenario-` | Actual fixture | Expected observation |
| --- | --- | --- |
| `heartbeat.tlog` | Two HEARTBEAT messages: quadrotor, ArduPilotMega, standby, unarmed | Two accepted frames; no threshold observation |
| `gps.tlog` | Two GPS_RAW_INT 3D fixes: latitude 41 to 41.01 degrees, longitude -87, altitude 120 m, 12 satellites | Two accepted frames; about 1,112 m/s exceeds the 100 m/s GPS review threshold |
| `altitude-control.tlog` | GLOBAL_POSITION_INT relative altitude 10 m; COMMAND_LONG MAV_CMD_DO_CHANGE_ALTITUDE (186), target 1/1, parameter 1 = 110 m, parameter 2 = MAV_FRAME_GLOBAL_RELATIVE_ALT (3); GLOBAL_POSITION_INT relative altitude 110 m | Three accepted frames; 50 m/s exceeds the 20 m/s vertical review threshold; altitude command is observed, not proven executed |
| `crc.tlog` | One heartbeat, high checksum byte XOR 1 after pymavlink serialization | Zero accepted frames; one CRC rejection; no decoded telemetry |

All checksums except the deliberate corruption are generated by pymavlink. Every browser result
passes the committed C parser compiled to `docs/mavframe.wasm`. `scenarios.js` only interprets
fields already accepted by that parser using the existing official message definitions.

Rate checks compare the same sender and message type using increasing capture timestamps no
more than five seconds apart; timestamp reversals disable them. GPS fixes must be 3D or better.
Thresholds are illustrative review rules, not aircraft-specific operating limits or intrusion
detection. Capture clocks, GPS data and unsigned commands can be inaccurate or unauthenticated.
A CRC check is not sender authentication, and command receipt is not an execution acknowledgement.

The selector loads public fixture bytes only in the current tab. Reset clears its loaded demo;
it never edits a file on disk. Uploaded captures are not encoded in URLs or stored by this flow.
Only the allowlisted public `scenario` ID and existing inspection filters are shareable.
Context review is bounded to 10,000 retained valid frames, 12 telemetry readings and 100 observations.

Run domain verification with `node --test tests/web/test_scenarios.mjs` after the native build.
