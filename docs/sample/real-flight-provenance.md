# Real telemetry sample provenance

`real-flight-redacted.tlog` is derived from the `flight.tlog` test capture in [dronekit/dronekit-la-testdata](https://github.com/dronekit/dronekit-la-testdata). The source project says its logs are freely available for testing, requires log-owner permission for contributions, and licenses all files under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Attribution: DroneKit-LA contributors, “DroneKit LA Test Data,” `flight.tlog`.

- Source URL: `https://raw.githubusercontent.com/dronekit/dronekit-la-testdata/master/flight.tlog`
- Source SHA-256: `16c79fedb900a61e9f67bca6133dd49a40a66f6b431e75138c8d9023c9a31523`
- Source size: 5,865,472 bytes
- Source dialect: ArduPilotMega, MAVLink v1; parser definitions are pinned to MAVLink XML commit `12c898d88ce18d24e8caf6338596e98c5005bc97`
- Transformation: all 12,642 `GPS_RAW_INT` and `GLOBAL_POSITION_INT` latitude/longitude values are set to zero and each affected MAVLink v1 CRC is recomputed. Record timestamps, other fields, frame order and unrelated bytes are retained. No frame was deliberately corrupted. The source itself is not included.
- Derivation command: `node tools/derive_public_sample.mjs /path/to/original/flight.tlog`
- Derived SHA-256: `d63c9b26edd06031bf11989b58869238b42b6abe03a278de997872c09d1f9c33`
- Derived parser counters (WebAssembly C parser): 163,851 valid frames; 0 CRC failures; 0 rejected flags; 388 sequence gaps with 2,877 estimated missing frames; 31 skipped bytes; 2,571 timestamp artifacts. The 31 skipped bytes and timestamp artifacts are not represented as proven corruption. Sequence gaps are estimates, not measured RF loss.

The file is a public test capture, not independently verified flight evidence. A derivative checksum proves which bytes were analyzed, not who operated a vehicle, where it flew, or that its reported telemetry is physically true. MAVLink CRC is not authentication.

The fast `sample-flight.tlog` is a separate synthetic fixture generated by `tools/gen_sample_tlog.py`; it deliberately contains CRC failures and gaps for deterministic tests. Do not conflate it with this real-world-derived capture.
