Privacy

Capture files are read in this browser tab. Mavframe does not upload them. The optional browser-local profile stores an email address and a salted password verifier; it does not verify real-world identity or encrypt saved data. Saved views contain only a name, theme and allowlisted route/filter/selection context. Capture bytes, decoded payloads, keys and tokens are not saved in a profile.

When you choose to open a feedback issue, share text, or use an external link, that action opens the destination shown by your browser. Review content before sending it. The source project is hosted on GitHub Pages; GitHub may process ordinary connection metadata.

Terms of Use

Mavframe and its parser are provided under the MIT license, with separate notices for MAVLink message definitions and bundled fonts. The tool is provided as-is without a response-time or support promise. CRC checks do not authenticate senders; signatures are carried but not verified. Confirm findings with your system’s own procedures before acting on telemetry.

Security & Offline Data

The app caches its public shell, parser, worker, styles, bundled synthetic and privacy-scrubbed real-flight samples, link-health module, and licenses in a Mavframe-scoped service-worker cache after an online visit. The service worker does not cache user files, generated reports, authentication responses, private API data or arbitrary URLs. Browsers may evict this cache. Offline use cannot be guaranteed before the first complete online preparation or after eviction.

Available offline after preparation: open the app shell, load the bundled synthetic or privacy-scrubbed real-flight sample, inspect frames, build a link-health timeline and export local reports. Requires a prior online visit: complete the app cache and bundled sample download. Requires network: first-time app assets, source repository, opening GitHub feedback, and other external links. Unsupported: Web Serial on browsers without the Web Serial API (including iOS Safari), server-backed accounts or remote recovery.

Profile records and saved settings remain in this browser’s site storage until removed or evicted. To remove Mavframe data, use this browser’s site-data controls for the Mavframe site; that can remove profiles and saved views. Clearing service-worker site data may require reopening the app online to prepare offline assets again. The origin may host other apps; Mavframe’s controls do not clear their data.

Service-worker updates wait for an explicit update action and do not delete unrelated origin caches. If an update fails, keep using the current page and retry when online. Export findings before sharing them; the original local capture must be opened separately on another device.
