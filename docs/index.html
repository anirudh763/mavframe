Files are read in this browser tab and never uploaded. Frames are found and CRC-checked by src/mavframe.c compiled to WebAssembly; payload fields of HEARTBEAT, SYS_STATUS, GPS_RAW_INT, ATTITUDE, GLOBAL_POSITION_INT and VFR_HUD are decoded from the official MAVLink XML definitions. MAVLink v1 frames are not parsed and count as skipped bytes. Message signatures are shown as present but are not verified. Captures up to 256 MB.
